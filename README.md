# Постмастер

Локальный AI-генератор постов для товаров на Flask. Вставьте ссылку на
карточку товара — приложение прочитает страницу и попросит языковую модель
BeatAPI написать оригинальный пост с заголовком, пользой, CTA и хэштегами.

Сайт работает на вашем компьютере, не использует базу данных и не сохраняет
историю генераций.

## Возможности

- генерация только по ссылке на товар — без ручного ввода названия и описания;
- 6 режимов: дружелюбный, продающий, экспертный, вдохновляющий, лаконичный
  и «Разные эмоции»;
- случайный творческий заход для каждой генерации;
- настройка тона, длины, количества эмодзи и стиля заголовка в `voice.md`;
- копирование готового поста одной кнопкой.

## Как это работает

1. Flask загружает страницу товара.
2. Из HTML достаются название, описание, цена, бренд и текст карточки.
3. Данные отправляются в языковую модель BeatAPI.
4. Модель возвращает готовый пост, который можно сразу скопировать.

Ключ BeatAPI хранится только в переменной окружения и не попадает в исходники,
браузер или тексты постов.

## Быстрый старт

Нужен Python 3.10 или новее.

### Windows (PowerShell)

```powershell
git clone <URL-репозитория>
cd Site3
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Если PowerShell запрещает запуск скрипта активации, можно обойтись без него:

```powershell
cd C:\Site3
.\.venv\Scripts\python.exe app.py
```

### Windows (cmd)

```bat
git clone <URL-репозитория>
cd Site3
python -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python app.py
```

### Linux / macOS

```bash
git clone <URL-репозитория>
cd Site3
python3 -m venv .venv
source .venv/bin/activate

python app.py
```

После запуска откройте: **http://127.0.0.1:5000**

Остановить сервер можно сочетанием `Ctrl+C`.

## Ключ BeatAPI

Создайте ключ в [личном кабинете BeatAPI](https://beatapi.io) и задайте его
в переменной окружения `BEATAPI_API_KEY`. Не добавляйте ключ в файлы проекта
и не публикуйте его.

### PowerShell

```powershell
$secure = Read-Host "Вставьте ключ BeatAPI" -AsSecureString
$key = [Runtime.InteropServices.Marshal]::PtrToStringBSTR(
  [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure)
)
[Environment]::SetEnvironmentVariable("BEATAPI_API_KEY", $key, "User")
Remove-Variable key, secure
```

После этого закройте и снова откройте терминал.

### cmd

```bat
set BEATAPI_API_KEY=ваш_ключ
python app.py
```

Команда `set` действует только в текущем окне командной строки.

### Linux / macOS

```bash
export BEATAPI_API_KEY="ваш_ключ"
python app.py
```

Можно указать конкретную модель через необязательную переменную
`BEATAPI_MODEL`. Если она не задана, приложение выбирает доступную бесплатную
модель через `/v1/models`.

## Как пользоваться

1. Вставьте ссылку на страницу товара.
2. Выберите настроение или оставьте «Разные эмоции».
3. Нажмите «Сгенерировать пост».
4. Проверьте текст и нажмите «Скопировать пост» — появится сообщение
   «Пост скопирован».

Для каждого поста случайно выбирается творческий заход: история, сравнение,
сценарий использования, наблюдение и т. п. Благодаря этому повторные генерации
отличаются друг от друга.

## Настройка стиля

Все настройки стиля собраны в `voice.md`:

| Параметр  | Значения                                                            |
|-----------|---------------------------------------------------------------------|
| `tone`    | разные, дружелюбный, продающий, экспертный, вдохновляющий, лаконичный |
| `length`  | короткая, средняя, длинная                                           |
| `emoji`   | целое число от 0 до 5                                                |
| `heading` | выгода, вопрос, прямой                                               |

Файл читается при каждом запросе, поэтому изменения применяются после
обновления страницы.

В `app.py` находятся комментарии, где менять:

- характер настроений — словарь `MOODS`;
- творческие заходы — `CREATIVE_ANGLES`;
- описание длины и стиля заголовков — `LENGTH_GUIDE` и `HEADING_GUIDE`;
- системную инструкцию для модели — `SYSTEM_PROMPT`.

## Ограничения

- Страница товара должна открываться без авторизации. Крупные маркетплейсы
  могут показывать капчу или блокировать автоматическую загрузку — тогда сайт
  попросит другую ссылку.
- Бесплатная модель BeatAPI обычно разрешает **1 успешную генерацию в минуту**.
  При превышении лимита сайт покажет, сколько секунд подождать.
- Для генерации нужен интернет: запросы идут на `api.beatapi.io`.
- Приложение не хранит ссылки и готовые посты на диске.

## Безопасность

Сайт предназначен для локального запуска. Не выставляйте его в открытый интернет
без дополнительной аутентификации и ограничения доступа. Текст страницы товара
считается недоверенным и передаётся модели только как источник фактов.
